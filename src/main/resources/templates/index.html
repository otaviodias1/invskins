Bem-vindo ao InvSkins

Gerenciamento de Skins e Inventários

Este sistema permite cadastrar, listar, atualizar e excluir skins e inventários.
Comece agora escolhendo uma das opções abaixo.

Recursos do sistema

  • Cadastro de Skins (nome, arma, raridade, preço, imagem)
  • Cadastro de Inventários
  • Organização de skins dentro de cada inventário

Como usar

  1. Cadastre suas skins
  2. Crie um inventário
  3. Adicione as skins ao inventário desejado
